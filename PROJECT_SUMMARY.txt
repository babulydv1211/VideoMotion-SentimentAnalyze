PROJECT OVERVIEW
================
A complete end-to-end deep learning system for multimodal video sentiment 
analysis using PyTorch, OpenCV, and transformers. The system analyzes videos
to predict emotional sentiment (Positive, Neutral, or Negative) through 
comprehensive motion analysis, spatial feature extraction, and temporal modeling.

✓ DEEP LEARNING ARCHITECTURE
  
  1. Spatial Feature Extractor
     - Architecture: ResNet50 (pretrained ImageNet weights)
     - Input: Video frames (B, 3, 224, 224)
     - Output: Feature vectors (B, 2048)
     - Purpose: Extract high-level visual content
  
  2. Optical Flow Processor
     - Method: Farneback Optical Flow (OpenCV)
     - Output: Motion magnitude and direction
     - Purpose: Capture scene motion dynamics
  
  3. Temporal Motion Model
     - Architecture: Bidirectional LSTM (2 layers)
     - Input: Optical flow features
     - Output: Temporal motion representations (B, 512)
     - Purpose: Learn temporal motion patterns
  
  4. Attention Mechanisms
     - Temporal Attention: Focus on important frames
     - Multi-head Attention: Learn diverse dependencies
     - Spatial Attention: Focus on motion regions
  
  5. Feature Fusion Layer
     - Method: Concatenation + Linear transformation
     - Combines spatial and temporal features
     - Output dimension: 512
  
  6. Sentiment Classifier
     - Architecture: 3-layer MLP
     - Output: 3-class probability distribution
     - Classes: Positive, Neutral, Negative
     - Loss: CrossEntropyLoss with Softmax

GETTING STARTED
===============

Quick Start (30 seconds):
  1. python setup.py               # Install dependencies
  2. streamlit run app.py          # Launch web app
  3. Open http://localhost:8501

Train Model:
  1. python main_train.py --use-dummy-data     # Test with dummy data
  2. python main_train.py --dataset-path ...   # Train on real data

Analyze Video:
  1. python main_inference.py video.mp4        # Analyze single video
  2. python main_inference.py videos/ --batch  # Batch processing
